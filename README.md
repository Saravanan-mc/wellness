**Wellness** is a web-based wellbeing project designed to bring mental health awareness, emotional self-reflection, healthy lifestyle guidance, and relaxation resources together in one place.

The project includes dedicated pages for breathing exercises, sleep improvement, mood tracking, journaling, nutrition, relationships, and emotional wellbeing.

> **Goal:** Make everyday wellbeing resources accessible through a simple, user-friendly web experience.

## ✨ Features

- 🏠 **Wellness Homepage** — A central starting point for exploring the platform.
- 🧠 **Mental Wellbeing** — Educational content and resources related to mental wellness.
- 💚 **Emotional Wellbeing** — Explore emotional awareness and self-reflection.
- 😊 **Emotion Detection** — A dedicated page for exploring emotion-detection functionality.
- 📊 **Mood Tracker** — A page for recording or reviewing moods, depending on the implemented functionality.
- 📔 **Personal Journal** — A space for journaling and reflecting on daily experiences.
- 🌬️ **Breathing Exercises** — Relaxation and guided breathing resources.
- 😴 **Better Sleep** — Information and habits that may help support healthier sleep.
- 🥗 **Nutrition** — Nutrition-related information and healthy lifestyle guidance.
- 🤝 **Relationships** — Content about relationships and interpersonal wellbeing.
- 🧘 **Therapy Resources** — A dedicated page for exploring therapy-related information.
- 🛠️ **Wellness Tools** — A central page for wellness utilities.
- 📚 **Resources** — Additional wellbeing information and useful resources.
- 📩 **Contact Page** — A dedicated page for contact-related information.

*The exact behavior of individual features depends on the implementation in each HTML file.*

## 🚀 Getting Started

### Prerequisites

You need:

- A modern web browser, such as Google Chrome, Firefox, or Microsoft Edge.
- Visual Studio Code or another code editor (optional).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Saravanan-mc/wellness.git
```

**2. Navigate to the project folder**

```bash
cd wellness
```

**3. Open the project**

Open `index.html` in your browser, or open the project folder in Visual Studio Code and use the Live Server extension.

No build process is required for basic static HTML pages. If any page depends on external services, APIs, or additional setup, follow the requirements in its source code.

## 🎯 Project Objectives

- Encourage awareness of mental and emotional wellbeing.
- Provide a centralized collection of wellbeing-related pages.
- Practice building multi-page websites with HTML, CSS, and JavaScript.

## 🔒 Privacy & Responsible Use

Wellbeing and journal entries can contain sensitive personal information. Any storage, analytics, or external API integration should be implemented with appropriate privacy protections.

This project is intended for educational and general wellbeing purposes. It is **not a substitute for professional medical advice, diagnosis, or treatment**. Emotion-detection features, if implemented, should not be treated as a clinical assessment.
